在上一篇里，我们让程序学会了“做选择”——根据不同的条件执行不同的代码。但还有一个问题没解决：**如果一件事要重复做很多次呢？**

比如：计算 1 到 100 的和。你不会傻到写一百行 `sum = sum + i`，你需要一种方式，让程序**自动重复执行某段代码**。

这就是**循环结构**。

C++ 里最常用的循环有三种：`for`、`while` 和 `do-while`。这一篇我们逐个来讲。

------

### 一、`for` 循环：最常用的循环

`for` 循环适合**知道要循环多少次**的场景。它的写法稍微有点复杂，但掌握之后会非常顺手。

```cpp
for (初始化; 条件; 更新) {
    // 循环体：条件为真时反复执行
}
```

三个部分各司其职：

- **初始化**：循环开始前执行一次，通常用来设置计数器
- **条件**：每次循环开始前判断，为真就执行循环体，为假就退出
- **更新**：每次循环体执行完后执行，通常用来改变计数器的值

看一个最经典的例子：**输出 1 到 10**

```cpp
for (int i = 1; i <= 10; i ++) {
    cout << i << endl;
}
```

执行顺序是这样的：

1. `int i = 1` —— 初始化，只执行一次
2. 判断 `i <= 10` —— 成立，进入循环体
3. 输出 `i` 的值
4. `i ++` —— i 变成 2
5. 回到第 2 步，重复直到 `i <= 10` 不成立

再比如**计算 1 到 100 的和**：

```cpp
int sum = 0;
for (int i = 1; i <= 100; i ++) {
    sum += i;  // 等价于 sum = sum + i
}
cout << sum << endl;
```

> `sum += i` 是 C++ 里的复合赋值运算符，意思是“把 `sum + i` 的结果存回 `sum`”。类似的还有 `sum -= i`、`sum *= i` 等，写起来更简洁。

`for` 循环的三个部分都不是必须的，但分号 `;` 不能少：

```cpp
int i = 1;
for (; i <= 10; ) {
    cout << i << endl;
    i ++;
}
```

但**通常情况下，把三个部分都写全**，代码更清晰，也不容易出错。

------

### 二、`while` 循环：条件前置的循环

`while` 循环适合**不知道具体要循环多少次，只知道“什么时候停”**的场景。

```cpp
while (条件) {
    // 条件为真时反复执行
}
```

`while` 的执行逻辑比 `for` 简单：每次循环前检查条件，为真就执行循环体，为假就跳出。

比如：**读入一组数，直到遇到 0 为止**

```cpp
int x;
cin >> x;
while (x != 0) {
    cout << "你输入了：" << x << endl;
    cin >> x;
}
```

这段代码会一直读入数字，直到用户输入 0 才停止。你事先不知道用户会输入几个数，所以用 `while` 比 `for` 更自然。

`for` 和 `while` 其实是**等价的**——任何 `for` 循环都可以改写成 `while`，反之亦然。选择哪个，取决于哪个更符合你的思维习惯。

```cpp
// for 循环
for (int i = 0; i < 10; i ++) {
    // ...
}

// 等价于 while 循环
int i = 0;
while (i < 10) {
    // ...
    i ++;
}
```

> **什么时候用 `for`，什么时候用 `while`？**
> 一个简单的经验：知道循环次数，用 `for`；不知道循环次数，只知道退出条件，用 `while`。

------

### 三、`do-while` 循环：条件后置，至少执行一次

`do-while` 和 `while` 的区别只有一点：**先执行一次循环体，再判断条件**。

```cpp
do {
    // 循环体：先执行一次
} while (条件);
```

这意味着，**不管条件成不成立，循环体至少会执行一次**。

比如：**让用户输入一个正数，如果输错了就重新输入**

```cpp
int x;
do {
    cout << "请输入一个正数：";
    cin >> x;
} while (x <= 0);
```

这段代码会先让用户输入一次，如果输入的数不大于 0，就继续问。`do-while` 非常适合“先做一次，再决定是否继续”的场景。

`do-while` 在实际比赛里用得不多，但在某些场景下（比如处理菜单输入、验证用户输入）很实用，值得了解。

------

### 四、循环控制：`break` 和 `continue`

循环里有两个关键字可以控制执行流程：

| 关键字     | 作用                                     |
| :--------- | :--------------------------------------- |
| `break`    | **跳出整个循环**，不再执行任何循环体     |
| `continue` | **跳过本次循环**，直接进入下一次循环判断 |

**`break` 示例：** 找到第一个能被 7 整除的数

```cpp
for (int i = 1; i <= 100; i ++) {
    if (i % 7 == 0) {
        cout << "第一个能被7整除的数是：" << i << endl;
        break;  // 找到就退出，不再继续
    }
}
```

**`continue` 示例：** 输出 1 到 10 中的所有奇数

```cpp
for (int i = 1; i <= 10; i ++) {
    if (i % 2 == 0) {
        continue;  // 是偶数就跳过，不输出
    }
    cout << i << endl;
}
```

> `break` 和 `continue` 的区别：`break` 是“彻底退出”，`continue` 是“跳过这一次，继续下一次”。

------

### 五、嵌套循环：循环里面的循环

循环里面还可以套循环，这叫**嵌套循环**。最经典的例子是**打印九九乘法表**：

```cpp
for (int i = 1; i <= 9; i ++) {
    for (int j = 1; j <= i; j ++) {
        cout << j << "*" << i << "=" << j * i << "\t";
    }
    cout << endl;
}
```

外层循环控制行数（1 到 9），内层循环控制每行打印多少列。这种“行-列”结构的题在 OJ 里很常见。

> **嵌套循环的层数不宜过多**，一般两层足够，三层以上可读性会急剧下降。如果发现需要三层以上循环，先想想有没有更简单的做法。

### 六、常见错误与注意事项

1. **循环条件写反导致死循环**

```cpp
for (int i = 1; i >= 1; i ++) {
    // i 永远 >= 1，永远不会停
}
```

2. **循环变量在循环体内被意外修改**

```cpp
for (int i = 1; i <= 10; i ++) {
    i = i - 1;  // ❌ 循环变量被改，导致死循环
}
```

3. **忘记更新循环变量**

```cpp
int i = 1;
while (i <= 10) {
    cout << i << endl;
    // ❌ 忘记 i ++，死循环
}
```

4. **`break` 和 `continue` 用混**

```cpp
for (int i = 1; i <= 10; i ++) {
    if (i == 5) {
        break;    // 到 5 就彻底退出
        // continue; // 到 5 就跳过，继续 6 7 8...
    }
    cout << i << endl;
}
```

5. **嵌套循环时，内层和外层的循环变量弄混**

```cpp
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5; i ++) {  // ❌ 内层用了 i++，应该是 j++
        cout << i << " " << j << endl;
    }
}
```

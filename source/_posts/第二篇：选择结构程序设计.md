在上一篇里，我们写的所有程序都是一条路走到黑：输入数据，处理数据，输出结果。程序像一台听话的机器，你让它做什么它就做什么。

但现实世界里的问题，很少是“一条直线”就能解决的。

比如：**判断一个数是奇数还是偶数。** 如果这个数是奇数，输出“奇数”；如果是偶数，输出“偶数”。程序需要根据不同的情况，执行不同的代码。

这时候就需要**选择结构**了。C++ 里最常用的选择结构就是 `if` 语句。

### 一、`if` 语句：最简单的选择

`if` 语句的写法非常直白：

```cpp
if (条件) {
    // 如果条件为真，就执行这里的代码
}
```

括号里的“条件”是一个**真/假**的判断，比如 `a > 0`，如果 `a` 确实大于 0，这个条件就是“真”，大括号里的代码就会执行；否则就跳过。

看一个完整的例子：

cpp

```cpp
#include <iostream>
using namespace std;

int main() {
    int a;
    cin >> a;

    if (a > 0) {
        cout << "a 是正数" << endl;
    }

    return 0;
}
```

如果输入 `5`，程序会输出“a 是正数”。如果输入 `-3`，条件不成立，程序什么也不输出，直接结束。

> 如果 `if` 后面只有一条语句，大括号可以省略，但**建议写上**。以后代码变多时，少一个大括号可能让你找半天 bug。

### 二、`if-else`：二选一

如果你的问题是“如果 A 成立，就做这件事；否则，就做另一件事”，那就需要 `if-else`：

cpp

```cpp
if (条件) {
    // 条件为真时执行
} else {
    // 条件为假时执行
}
```

用这个来写“判断奇偶”：

```cpp
int a;
cin >> a;

if (a % 2 == 0) {
    cout << "偶数" << endl;
} else {
    cout << "奇数" << endl;
}
```

`a % 2 == 0` 的意思是“a 除以 2 的余数等于 0”。如果成立，就是偶数；否则就是奇数。

### 三、`if-else if-else`：多选一

当你有多个互斥的条件需要判断时，可以用 `else if`：

```cpp
if (条件1) {
    // 条件1为真时执行
} else if (条件2) {
    // 条件1为假，但条件2为真时执行
} else {
    // 所有条件都为假时执行
}
```

比如根据分数输出等级：

```cpp
int score;
cin >> score;

if (score >= 90) {
    cout << "优秀" << endl;
} else if (score >= 80) {
    cout << "良好" << endl;
} else if (score >= 60) {
    cout << "及格" << endl;
} else {
    cout << "不及格" << endl;
}
```

注意：`if-else if` 是按顺序判断的，一旦某个条件满足，后面的条件就不再判断了。所以条件的顺序很重要。

### 四、嵌套 if：条件里的条件

有时候，你需要在满足一个条件之后，再判断另一个条件。比如：

> 如果某个数是正数，再判断它是不是偶数。

这就是“嵌套 `if`”的典型场景——在一个 `if` 或 `else` 的代码块里，再写一个 `if` 语句。

```cpp
int a;
cin >> a;

if (a > 0) {
    // 外层条件：a 是正数
    if (a % 2 == 0) {
        cout << "a 是正偶数" << endl;
    } else {
        cout << "a 是正奇数" << endl;
    }
} else {
    cout << "a 不是正数" << endl;
}
```

这种写法的逻辑很清晰：外层先判断 `a > 0`，只有满足这个条件，才会进入内层的判断。不满足时，直接跳到最外层的 `else`，不会执行任何内层代码。

再看一个例子——判断三个数中的最大值：

```cpp
int a, b, c;
cin >> a >> b >> c;

if (a >= b) {
    if (a >= c) {
        cout << "最大值是 a" << endl;
    } else {
        cout << "最大值是 c" << endl;
    }
} else {
    if (b >= c) {
        cout << "最大值是 b" << endl;
    } else {
        cout << "最大值是 c" << endl;
    }
}
```

这段代码的逻辑是通过两两比较，逐步缩小范围，最终确定最大值。

> **注意**：嵌套 `if` 的层数不宜过多。一般嵌套两到三层还比较清晰，如果超过三层，代码会变得难以阅读。通常可以用 `else if` 或重构代码来简化逻辑，避免出现“俄罗斯套娃”式的多层嵌套。

#### `else` 的“就近匹配”原则

在嵌套 `if` 里，有一个容易让新手困惑的问题：**`else` 到底和哪个 `if` 配对？**

```cpp
if (a > 0)
    if (a % 2 == 0)
        cout << "偶数" << endl;
else
    cout << "这里属于谁？" << endl;
```

答案是：**`else` 会与离它最近的、尚未配对的 `if` 配对**。在上面的代码中，`else` 属于内层 `if (a % 2 == 0)`，而不是外层 `if (a > 0)`。

为了避免这种歧义，**强烈建议在嵌套 `if` 中使用大括号 `{}`**，明确标出每个 `if` 的作用范围：

```cpp
if (a > 0) {
    if (a % 2 == 0) {
        cout << "偶数" << endl;
    }
} else {
    cout << "a 不是正数" << endl;  // 现在明确属于外层 if
}
```

这样写，代码的意图就一目了然了。

### 五、关系运算符和逻辑运算符

条件判断离不开运算符，这一节把常用的都列出来。

**关系运算符**（用来比较两个值）：

| 运算符 | 含义     | 示例     |
| :----- | :------- | :------- |
| `>`    | 大于     | `a > 5`  |
| `<`    | 小于     | `a < 5`  |
| `>=`   | 大于等于 | `a >= 5` |
| `<=`   | 小于等于 | `a <= 5` |
| `==`   | 等于     | `a == 5` |
| `!=`   | 不等于   | `a != 5` |

**逻辑运算符**（用来组合多个条件）：

| 运算符 | 含义                 | 示例              |
| :----- | :------------------- | :---------------- |
| `&&`   | 与（两个条件都成立） | `a > 0 && a < 10` |
| `||`   | 或（至少一个成立）   | `a < 0 || a > 10` |
| `!`    | 非（取反）           | `!(a == 5)`       |

> **⚠️ 新手最常踩的坑：`=` 和 `==` 弄混。** `=` 是赋值，`==` 才是判断相等。如果你不小心写了 `if (a = 5)`，编译器不会报错，而是会把 5 赋给 a，然后条件永远为真。这种 bug 很难发现，务必小心。

### 六、`switch` 语句：多路分支的另一种写法

当你要判断的是“一个变量的值等于哪个常量”时，可以用 `switch`，比 `if-else if` 更清晰。

```cpp
int day;
cin >> day;

switch (day) {
    case 1:
        cout << "星期一" << endl;
        break;
    case 2:
        cout << "星期二" << endl;
        break;
    case 3:
        cout << "星期三" << endl;
        break;
    default:
        cout << "无效数字" << endl;
        break;
}
```



- `case` 后面跟的是常量值，比如 `1`、`2`。
- `break` 的作用是跳出 `switch`，如果不写，程序会继续执行下一个 `case`（这叫“穿透”）。
- `default` 是可选的，表示所有 `case` 都不匹配时执行的代码。

`switch` 和 `if-else if` 的区别：

|            | `if-else if`       | `switch`               |
| :--------- | :----------------- | :--------------------- |
| 判断条件   | 可以是任意表达式   | 只能判断整数或字符常量 |
| 适用场景   | 复杂条件、范围判断 | 离散值匹配             |
| 代码可读性 | 条件越多越乱       | 离散值时更清晰         |

在实际比赛中，`if-else` 的使用频率远高于 `switch`。但了解 `switch` 可以让你在读别人的代码时更顺畅。

### 七、常见错误与注意事项

1. **条件里用了赋值 `=` 而不是比较 `==`**

```cpp
if (a = 5) {   // ❌ 这是赋值，不是判断
    // 永远会执行
}
```

1. **忘记大括号**

```cpp
if (a > 0)
    cout << "正数" << endl;
    cout << "这行不管条件成不成立都会执行" << endl;  // ❌ 只有上一行属于 if
```

1. **`else if` 的顺序不对**

把范围写反了，比如先判断 `>= 60`，再判断 `>= 90`，那 `>= 90` 的代码永远不会执行。

1. **`switch` 漏写 `break`**

```cpp
case 1:
    cout << "星期一" << endl;   // ❌ 没有 break，会继续执行 case 2
case 2:
    cout << "星期二" << endl;
    break;
```

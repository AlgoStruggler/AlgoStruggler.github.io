在上一篇循环里，我们学会了一件事：让程序重复做某件事。但还有一个问题一直没解决——**如果数据量很大，怎么存？**

比如：给你 100 个整数，让你找出其中的最大值。你总不能声明 100 个变量吧？`int a1, a2, a3, ...` 写到天亮也写不完。

这时候就需要**数组**了。

数组可以理解成一排连续的盒子，所有盒子都贴着编号（下标），你可以通过编号来访问每一个盒子。这些盒子在内存里是紧挨着的，所以访问速度非常快，这也是数组在算法题中被广泛使用的原因之一。

### 一、数组：连续的一排盒子

数组的声明方式很简单：

```cpp
int a[100]; // 声明一个能装 100 个整数的数组，下标从 0 到 99
```

- `int` 表示数组里每个元素的类型
- `a` 是数组的名字
- `[100]` 表示数组的大小（能装 100 个元素）
- 下标从 `0` 开始，到 `99` 结束，**没有 `a[100]`**

存取元素的方式和普通变量一样，用下标来访问：

```cpp
a[0] = 5; // 把 5 放进第一个盒子
a[1] = 3; // 把 3 放进第二个盒子
cout << a[0] + a[1]; // 输出 8
```

结合循环，数组的威力就出来了：

```cpp
int a[100];
int n;
cin >> n;          // 输入实际要用的数据个数

for (int i = 0; i < n; i ++) {
    cin >> a[i];   // 循环读入 n 个数，存入 a[0] 到 a[n-1]
}

int sum = 0;
for (int i = 0; i < n; i ++) {
    sum += a[i];   // 累加
}
cout << sum << endl;
```

这就是数组最基础的应用——**批量存储，批量处理**。

> **新手常见错误：数组下标越界。** 如果你声明了 `int a[100]`，但你写了 `a[100] = 5`，下标 100 已经超出了 0-99 的范围。编译器不会报错，但程序运行时会访问到不该访问的内存，导致不可预测的结果。**下标越界是 C/C++ 里最严重的问题之一，务必小心。**

根据我们中国人的习惯，下标习惯从 `1` 开始，所以为了防止这种情况，我们会预先多申请一些内存，然后丢弃第 `0` 位，让数组的下标从`1` 开始。

比如上面的数组我们可以变成

```cpp
int a[105]; //多出来的 5 位是我们为了防止数组下标越界额外定义的
    
int n;
cin >> n;

for (int i = 1; i <= n; i ++) { //这样数组下标就可以从 1 开始了
	cin >> a[i];
}
```

### 二、数组的初始化

声明数组时，可以同时赋初值：

```cpp
int a[5] = {1, 2, 3, 4, 5}; // 完全初始化
int b[5] = {1, 2, 3}; // 部分初始化，剩下自动补 0
int c[] = {1, 2, 3, 4, 5}; // 不指定大小，编译器自动推断为 5
```

如果不初始化，数组里的值是**不确定的**，会残留之前内存里的随机数据：

```cpp
int a[5]; // 里面的值可能是任何东西，不要直接使用
```

因此，**声明数组后如果马上要用，务必初始化**。一个常见的做法是全部初始化为 0：

```cpp
int a[100] = {0};   // 所有元素都是 0
```

### 三、数组的常见操作

#### 1. 遍历

遍历就是从头到尾访问每一个元素，通常用 `for` 循环实现：

```cpp
for (int i = 1; i <= n; i ++) {
    cout << a[i] << " ";
}
```

#### 2. 查找

找出数组中某个值的位置：

```cpp
int target;
cin >> target;
int pos = -1;  // -1 表示没找到

for (int i = 0; i < n; i ++) {
    if (a[i] == target) {
        pos = i;
        break;
    }
}
```

#### 3. 求最大值/最小值

```cpp
int max_val = a[0]; // 先把第一个元素当作最大值

for (int i = 1; i < n; i ++) {
    if (a[i] > max_val) {
        max_val = a[i];
    }
}
// 求最小值同理，读者可以自行体会
```

#### 4. 反转

把数组的顺序倒过来：

```cpp
for (int i = 0; i < n / 2; i ++) {
    swap(a[i], a[n - 1 - i]);
}
```

`swap` 是 C++ 标准库提供的交换函数，可以交换两个变量的值。这在竞赛中可以让你少写三行临时变量的代码，非常方便。

### 四、多维数组

数组的数组叫**多维数组**。最常用的是二维数组，可以理解成一张表格（行和列）：

读者如果学过代数里的矩阵或行列式，更能容易理解。

```cpp
int a[3][4];  // 3 行 4 列的表格
```

访问方式：`a[行号][列号]`

```cpp
for (int i = 0; i < 3; i ++) {
    for (int j = 0; j < 4; j ++) {
        cin >> a[i][j];
    }
}
```

二维数组常用于处理矩阵、迷宫、棋盘等问题。比如计算一个 3x3 矩阵的对角线之和：

```c++
int a[3][3];
int sum = 0;

for (int i = 0; i < 3; i ++) {
    for (int j = 0; j < 3; j ++) {
        cin >> a[i][j];
        if (i == j) { //如果行号和列号相等，即为对角线上的元素
            sum += a[i][j];
        }
    }
}
```

在算法竞赛中，你遇到的题如果涉及“网格”、“地图”、“棋盘”，大概率需要用二维数组来存储数据。三维及以上就比较少见了，但在某些动态规划题里会出现。

### 五、字符数组与字符串

在 C++ 里，字符串可以用两种方式表示：

#### 1. C 风格字符串（字符数组）

```c++
char s[100] = "Hello"; // 字符数组
cout << s << endl; // 输出 Hello
```

C 风格字符串以 `\0`（空字符）结尾，用来标记字符串的结束：

```c++
char s[100] = {'H', 'e', 'l', 'l', 'o', '\0'};
```

操作 C 风格字符串需要用 `<cstring>` 里的函数：

```c++
#include <cstring>

char s1[100] = "Hello";
char s2[100] = "World";

strlen(s1); // 获取长度：5
strcpy(s2, s1); // 复制：把 s1 复制到 s2
strcmp(s1, s2); // 比较：0 表示相等
strcat(s1, s2); // 拼接：s1 变成 "HelloWorld"
```

#### 2. C++ 风格的 `string`（推荐）

C++ 提供了更方便的 `string` 类型：

```cpp
#include <string>

string s1 = "Hello";
string s2 = "World";

cout << s1 + " " + s2 << endl; // 拼接 "Hello World"
cout << s1.size() << endl; // 长度
cout << s1[0] << endl; // 下标访问：H
```

**注意：字符串的下标默认从 `0` 开始**

在 ACM 里，**`string` 用起来比字符数组方便得多**，也安全得多。

`cin >>` 和 `getline` 的混用问题是新手经常会踩的坑：`cin >>` 读入字符串时遇到空格就停，而 `getline` 会读一整行，直到遇到换行符。如果 `cin >>` 后面跟 `getline`，`getline` 会读走残留的换行符，导致看起来“跳过了”一次输入。解决办法是在 `cin >>` 后面加一行 `cin.ignore()`。

**天梯赛常见的考法：`getline` 和 `cin.ignore`**

### 六、常见错误与注意事项

1. **数组大小开得不够，导致越界**

```c++
int a[10];
for (int i = 1; i <= 10; i ++) {  // ❌ i = 10 时越界
    a[i] = i;
}
```

2. **数组大小开得太大，导致栈溢出**

```c++
int a[10000000];  // ❌ 太大了，可能会爆栈
```

在 ACM 里，如果数组特别大（比如 10⁶ 以上），可以考虑开成**全局变量**，或者用 `std::vector` 动态分配。

3. **字符串忘记包含头文件**

```c++
#include <string> // string 类型需要这个头文件
#include <cstring> // strlen、strcmp 等函数需要这个
```

4. **混淆 C 风格字符串和 `string` 的初始化方式**

```c++
char s[100] = "Hello"; // ✅ 字符数组
string s = "Hello"; // ✅ string
char s = "Hello"; // ❌ 不能用字符串给单个字符赋值
```
